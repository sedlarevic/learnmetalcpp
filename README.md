# NOTE

To get the successful build, copy [metal-cpp](https://github.com/bkaradzic/metal-cpp) and metal-cpp-extensions (copy from the LEARNMetalCPP tutorial) into the root of your project.
After that, add Header Search Paths in Build Settings (should be $(PROJECT_DIR)metal-cpp and $(PROJECT_DIR)metal-cpp-extensions).

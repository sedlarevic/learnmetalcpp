# NOTE
To get the successful build:

1. Copy [metal-cpp](https://github.com/bkaradzic/metal-cpp) and metal-cpp-extensions (copy from the LEARNMetalCPP tutorial) into the root of your project.
2. Add Header Search Paths in Build Settings (should be \$(PROJECT_DIR)metal-cpp and \$(PROJECT_DIR)metal-cpp-extensions).
